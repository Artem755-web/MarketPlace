# Rental Marketplace API

A RESTful API for a peer-to-peer item rental marketplace built with Java 17, Spring Boot, and PostgreSQL.

## 🛠 Tech Stack
* **Java 17**
* **Spring Boot 3** (Web, Data JPA, Security, Test)
* **PostgreSQL & Hibernate**
* **Docker & Docker Compose**
* **JWT (JSON Web Tokens)**
* **Swagger / OpenAPI 3**

## 🚀 Key Features
* User registration and JWT authentication
* Role-based access control (User, Admin)
* Item listing management (CRUD operations)
* Rental request workflows and booking status management
* Unit and integration testing with JUnit 5 & Mockito
